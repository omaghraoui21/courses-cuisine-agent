# Compagnon eve — non déployé avec le site

Initialisé avec eve 0.80.1. Fournit des instructions et un outil de calcul déclaratif. Le site déployé fonctionne indépendamment. Ce compagnon nécessite son propre runtime Node, son authentification et ses secrets avant usage. Aucun outil de commande ou connexion Glovo n’est livré ici.

Développement : `npm install`, `npm run typecheck`, puis `npm exec -- eve dev`. Le modèle et le budget sont à configurer avant requête réelle. Ne pas exposer les endpoints sans autorisation.
